# Запуск сайта на VPS

Пошаговая инструкция запуска на mishale74.ru. Устройство сервера — [SERVER.md](SERVER.md). Чек-лист — ТЗ §16.

## 0. Что должно быть готово до запуска

| Что                                                            | Где в коде или у кого                   | Без этого                                     |
| -------------------------------------------------------------- | --------------------------------------- | --------------------------------------------- |
| Уведомление в Роскомнадзор (компания в реестре операторов ПДн) | Компания, 05 раздел 4                   | Штраф за сбор заявок без уведомления          |
| Дата «Цена действует с» = день запуска                         | Админка → «Комплектации для всех домов» | На сайте цены без даты                        |
| Тексты политики и согласия проверены юристом                   | `/politika`, `/soglasie`                | Риск по 152-ФЗ                                |
| Права на визуализации домов                                    | 05, раздел 11                           | Если права нет — заменить картинки до запуска |
| Ключ API YouGile и колонка «Новая заявка»                      | `/etc/mishale/mishale.env` на сервере   | Формы показывают «позвоните нам»              |

## DNS

20.11.2026 у регистратора DNS-серверы сменены с Tilda на `ns1.ultravds.com`, `ns2.ultravds.com`. Смена в зоне .ru проходит за несколько часов – сутки. Записи — в панели UltraVDS:

| Имя            | Тип | Значение       |
| -------------- | --- | -------------- |
| `mishale74.ru` | A   | `45.15.252.47` |
| `www`          | A   | `45.15.252.47` |

Почты на домене нет (MX и TXT не было, проверено 07.11.2026). Старый сайт Tilda — `176.57.67.214`.

Проверка, что домен смотрит на сервер:

```
nslookup mishale74.ru 8.8.8.8
```

## 1. Деплой

```
bash scripts/deploy.sh
npm run smoke -- http://45.15.252.47
```

Каждая выкладка — по команде владельца проекта. Затем вручную: отправить заявку с каждой формы (заявка, проект, квиз) и убедиться, что задачи появились в YouGile с источником и UTM. Проверить с телефона.

## 2. День запуска

1. Отдельным коммитом: `lib/site.ts` → `indexable: true` (счётчик Метрики 114223473 уже подключён, список адресов — `components/Metrika.tsx`). Проверки (`npm run check`, `npm run build`, `npm run test:e2e`) — тест «главная закрыта от индексации» при этом нужно обновить в том же коммите.
2. Деплой (раздел 1).
3. Когда `nslookup` показывает `45.15.252.47`, сертификат выпустится сам в течение 10 минут (SERVER.md, «HTTPS»).
4. Проверка:
   ```
   npm run smoke -- https://mishale74.ru
   ```
   Ожидаемо: все «ok», robots.txt открыт, `X-Robots-Tag: нет`.
5. Тестовая заявка с боевого домена → YouGile.

## 3. После запуска

- Яндекс Вебмастер: добавить сайт (если нет), sitemap `https://mishale74.ru/sitemap.xml`, переобход главной и проектов, регион — Миасс.
- Метрика: цели срабатывают (заявка, квиз, телефон, WhatsApp, фильтр), Вебвизор пишет.
- PageSpeed Insights, мобильный: главная и страница проекта — цели ТЗ §12.
- Ссылки на сайт в Яндекс Бизнесе, 2ГИС, Авито, VK, Telegram, объявлениях Директа — на новые адреса.
- Через 1–2 недели: Вебмастер → «Страницы в поиске», старые адреса заменились новыми, нет ошибок 404.

## 4. Откат

- Ошибка в новом релизе — откат на прошлый релиз (SERVER.md, «Выкладка»).
- Критичная ошибка, которую нельзя исправить за час — вернуть в панели UltraVDS `A 176.57.67.214` для `mishale74.ru` и `www` (старый сайт Tilda, пока он оплачен).
