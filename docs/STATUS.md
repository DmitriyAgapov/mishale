## Решения

- Next.js 16.4.2 с `cacheComponents` и `partialPrefetching` (по умолчанию в create-next-app). Версии пакетов — не новее 2 недель на дату установки, закреплены точно.
- `.npmrc` `legacy-peer-deps=true` — обход падения npm 10 на цикле peer-зависимостей vite/vitest (README).
- Шрифт Manrope (латиница + кириллица, 400/600/800) через `next/font`.
- Цвета: фирменный `#894720` — средний цвет древесной текстуры логотипа; акцент `#2f6b3a`. Контраст белого текста на фирменном ~6,8:1.
- Логотип: `public/logo.svg`, 9 КБ — векторизация PNG с текущего сайта (potrace по альфа-каналу), текстура дерева заменена сплошным цветом. Исходник у компании запрошен.
- Индексация — константа `site.indexable` в `lib/site.ts`, не переменная: Amvera не передаёт переменные на этапе сборки, а `robots.txt` собирается статически.
- Поле-ловушка проверяется в `guard.ts`, а не схемой: бот получает «успех» (200) и не узнаёт, что попался.
- Уведомление о недоставленной заявке в Telegram из ТЗ §9 не сделано: Telegram API может быть недоступен с российского хостинга. Пока — запись в лог Amvera без персональных данных.
- Данные проектов на этапе 2 взяты с текущего сайта (02.11.2026): названия, площади, число и размер модулей, визуализации фасадов, планировки (кроме 35 и 60 м² — у них планировка от другого проекта). Цен по проектам нет — «Цена по запросу», пока компания не пришлёт. «Кому подходит» и FAQ написаны исполнителем — на проверку компании.
- Общий состав конструкции (`settings.construction`) — с текущего сайта; показывается на странице проекта, пока у проекта нет своих характеристик.
- Без подтверждённых данных не пишем сроки монтажа на участке — только «назовём для вашего проекта».
- Несуществующий проект → настоящий 404 через `proxy.ts`: при частичном пререндере оболочка страницы уходит со статусом 200 раньше `notFound()` (docs: not-found.md, streaming.md).
- Меню на телефоне — `<details>` (работает без JS) + маленький клиентский компонент, закрывающий меню после перехода.
- Форма: react-hook-form + zod, `startedAt` в ref (правила React Compiler запрещают `Date.now()` в рендере), поле-ловушка, UTM из localStorage, цели Метрики — заглушки до подключения счётчика.
- Линейка (решение пользователя от 05.11.2026): 10 проектов — 2 малых дома (20, 35 м², 2 модуля), 4 средних (45, 60, 75, 90 м²), 2 больших (105, 120 м²), 2 бани. Поле `category` в данных проекта; каталог разбит на группы, пустая группа не выводится.

Данные — поле `banyaVariant` проекта; свои планировка, цены, опции, характеристики, SEO; фото берутся от основного проекта, если своих нет. Пока все варианты `published: false` — данных нет, адреса отдают 404.
- Бани `banya-1`, `banya-2` — заготовки с `published: false`. Адреса временные: переименовать до публикации, после публикации адрес не менять.
