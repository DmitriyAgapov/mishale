## Решения

- Next.js 16.4.2 с `cacheComponents` и `partialPrefetching` (по умолчанию в create-next-app). Версии пакетов — не новее 2 недель на дату установки, закреплены точно.
- `.npmrc` `legacy-peer-deps=true` — обход падения npm 10 на цикле peer-зависимостей vite/vitest (README).
- Шрифт Manrope (латиница + кириллица, 400/600/800) через `next/font`.
- Цвета: фирменный `#894720` — средний цвет древесной текстуры логотипа; акцент `#2f6b3a`. Контраст белого текста на фирменном ~6,8:1.
- Логотип: `public/logo.svg`, 9 КБ — векторизация PNG с текущего сайта (potrace по альфа-каналу), текстура дерева заменена сплошным цветом. Исходник у компании запрошен.
- Индексация — константа `site.indexable` в `lib/site.ts`, не переменная: Amvera не передаёт переменные на этапе сборки, а `robots.txt` собирается статически.
- Поле-ловушка проверяется в `guard.ts`, а не схемой: бот получает «успех» (200) и не узнаёт, что попался.
- Уведомление о недоставленной заявке в Telegram из ТЗ §9 не сделано: Telegram API может быть недоступен с российского хостинга. Пока — запись в лог Amvera без персональных данных.

## Открытые вопросы

- YouGile API v2: адрес, формат `description` (HTML?) и `stickers` взяты не из документации (портал не читается автоматически). Проверить на реальном ключе.
